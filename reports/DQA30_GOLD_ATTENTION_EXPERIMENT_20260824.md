# 图谱是否改善长上下文注意力：可行性与70题因果归因实验

## 显式注意力的可行性

LLM 可以在特定推理框架下输出内部注意力张量，但当前 Ollama 运行路径不能。Ollama 的聊天接口可返回生成 token 的 log-prob，却不返回输入 token 间的 attention weight。Hugging Face Transformers 在模型支持时可通过 `output_attentions=True` 返回每层注意力，典型张量形状为 batch、head、query token、key token。然而，本机 Qwen3.5-9B 只有 Ollama/GGUF 权重；当前 PyTorch 为 CPU 版，CUDA 不可用；RTX 5070 仅有 12 GB 显存。

Qwen3.5-9B 还是混合架构。32 层按三个线性注意力层和一个全注意力层循环，只有八个全注意力层适合传统 token-to-token attention 分析。官方 BF16 权重约 19 GB，已经超过本机显存。若在 8K token 上显式保存八层、16头、FP16全注意力，注意力矩阵本身约需16 GB，尚未计算模型权重和中间激活。因此，本机不能对同一个9B长上下文模型直接导出完整 attention tensor。让模型在文本中自报“注意力分数”不属于内部注意力，不能作为论文指标。

## 当前可执行的因果注意力代理

本实验采用更接近“模型是否真正使用证据”的因果指标。对每道题，分别构造 G7 图谱上下文和普通压缩摘要上下文，读取正确选项的首 token log-prob。随后只遮挡该方法上下文中的金标证据，再次计算正确选项 log-prob。定义金标证据贡献为完整上下文 log-prob 减去遮挡后 log-prob。正值表示金标证据提高了正确答案概率，数值越大表示模型答案越依赖金标证据。

DetectiveQA 的 `clue_position` 和 `answer_position` 被共同定义为金标证据。图谱条件只遮挡原始块内的对应编号段落，并删除源自这些段落的图谱关系；块内其余文字保持不变。压缩条件以 BGE-M3 将金标段落对齐到摘要句子，并在相似度至少0.55时遮挡最相似句子。两种条件使用同一 Qwen3.5-9B、关闭 thinking、温度0和 A–D token log-prob 评分。

## 结果

实验覆盖新增10本小说的全部70题。G7 在40/70题中包含至少一个金标原段落，金标保留率为57.1%。压缩摘要在0.55阈值下70/70题均存在语义对齐句；当阈值提高到0.65和0.70时，保留率分别为90.0%和72.9%。因此，压缩方法当前最明显的优势是覆盖，而不是单题证据强度。

全体70题中，图谱的平均金标 log-prob 贡献为0.149，中位数为0，正向比例为32.9%。压缩的平均贡献为0.133，中位数为0.034，正向比例为58.6%。图谱减压缩的配对均值为0.016，中位数为−0.013；只有47.1%的题图谱贡献更大。按小说聚类 bootstrap 的95%区间为−0.145至0.176，明显跨越零。因此，全体数据不支持“图谱普遍提高金标注意力”的结论。

在图谱确实召回金标段落的40题中，图谱平均贡献为0.261，压缩为0.167，配对差为+0.094；图谱贡献更大的比例为55.0%。该子集中，基于 A–D log-prob 最大值的图谱准确率为62.5%，压缩为60.0%。这是一条正向但尚未验证的条件效应：图谱命中正确证据时，可能使小模型更依赖该证据。

在图谱漏掉金标的30题中，图谱贡献按定义为0，图谱准确率为30.0%，压缩为50.0%。这一差距说明当前主要瓶颈是检索覆盖，而不是模型看到金标后仍无法利用。小说93和97的图谱贡献弱，与此前两本小说较低的G7答题成绩一致；小说99、103、104和107出现更明显的图谱条件优势，但小说间方向不稳定。

## 论文可用结论

当前证据不支持写成“图谱整体提高了LLM对金标段落的注意力”。更准确的结论是：图谱具有条件性的证据聚焦效应。当图谱成功召回金标段落时，正确选项对金标证据的平均因果依赖高于压缩；然而，图谱仅覆盖57.1%的题，且小说间异质性使总体优势消失。图谱方法的下一步突破应优先提高金标证据覆盖率，并保持紧证据预算，而不是继续增加上下文长度。

## 下一步严格实验

下一版应首先将 `answer_position` 与 `clue_position` 分开。显式答案段落通常是正向证据，推理 clue 可能包含早期怀疑、反事实或干扰内容；本实验将二者一起遮挡，解释上仍不够纯。主指标应设为 answer-position contribution，clue-position contribution 作为机制分解。

其次，应建立同证据、同 token、同位置的受控比较。平坦条件和图谱条件必须看到完全相同的原文块；图谱条件只增加关系结构或图谱排序。这样才能区分“图谱找到了不同证据”和“图谱帮助模型调度同一批证据”。当前运营条件比较同时包含检索和组织两个作用。

最后，若需要真正的内部 attention 图，应在至少24 GB显存的环境下载官方 Transformers 权重，使用支持返回权重的 eager attention，并只聚合答案 query token 指向金标 span 的注意力，不保存完整矩阵。本机可先用更小的同系列模型做机制探针，但该结果不能替代9B主实验。无论是否获得内部 attention，因果遮挡的 log-prob 变化都应保留为主指标，因为 attention weight 本身不能证明证据对答案有因果作用。
