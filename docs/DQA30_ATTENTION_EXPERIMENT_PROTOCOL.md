# DetectiveQA 30本注意力实验预注册草案

冻结基线：20本先导集；新增验证集：小说93、97、99、100、103、104、105、106、107、108。
统一答题模型为 qwen3.5:9b，think=false、温度0、无答案掩码。

## 数据纪律

- 20本只用于提出注意力机制、设定阈值和消融设计。
- 新10本只用于冻结后的验证，不根据其金标修改提示、路由或阈值。
- 每题保存G1/G2/G3的完整检索段落、图关系提示、排列稳定性、G4/G5路由和三个文本基线。
- 题目+选项基线Q0只用于困难子集分层，不替代全量主指标。
- 早期20本图谱由7B抽取；涉及图结构质量的正式30本比较必须在20本也用同一9B v4流程重建后报告。
  在此之前，20+10合并结果仅作机制探索，新增10本可作独立9B验证。

## A. 检索注意力实验（无需模型内部权重）

1. 原文注意：只给BGE-M3+BM25 RRF段落，即B3。
2. 图谱注意：在完全相同原文段落上增加经原文定位的高价值关系，即G1。
3. 图谱打乱消融：关系数量不变，随机置换到同小说其他题，检验收益是否来自语义而非额外token。
4. 关系类型消融：分别移除时间、动机、手段、机会、支持/反驳关系。
5. 关系预算曲线：每题提供0、1、2、4、6条图关系，测准确率—token成本曲线。
6. 位置消融：图关系放在原文前、原文后或对应段落旁，测试有限上下文中的注意分配。

主比较为G1-B3；所有消融保持原文段落、模型、温度、上下文上限和选项顺序一致。

## B. 选项注意与稳定性实验

- 使用原序、逆序、循环序三次图谱作答。
- 记录三排列一致、二比一多数、完全分歧。
- G4：原序与逆序一致时采用图谱答案，否则回退B1。
- G5：三排列至少两票一致时采用多数答案，否则回退B1。
- 比较稳定题与不稳定题的图关系数、检索重叠率、题型和正确率。
- 路由规则不得读取金标或“某方法历史上更擅长某类题”的测试集统计。

## C. 上下文片段注意实验

对每题的固定检索包做可复现遮挡：

- 删除每个段落，计算答案变化和置信度变化；
- 删除每条图关系，计算答案变化；
- 只保留最终解答附近、线索首次出现附近或尾部段落；
- 比较金标线索命中与模型决定性片段是否一致。

这些实验得到的是因果遮挡重要性，不宣称等同于Transformer内部attention权重。

## D. 模型内部attention实验边界

Ollama聊天接口不返回逐层attention矩阵。若需要内部attention，必须另建Transformers推理路径并固定同一量化/精度、
tokenizer、上下文和生成参数。内部attention实验与Ollama主准确率实验分开报告，避免把后端差异解释成图谱收益。

## 预注册指标

- 全量准确率；
- Q0答错困难子集准确率；
- G1相对B3、G5相对B1的逐题McNemar检验；
- 按小说聚类bootstrap 95%区间；
- 每题检索字符数、图关系数、排列一致率、回退率；
- 每增加1000上下文token带来的准确率变化；
- 遮挡后答案翻转率与正确答案概率/置信度变化。

新增10本的统一评估器为 scripts/run_dqa30_batch_eval.py，每题结果中的 retrieval 与
attention_features 字段作为后续消融输入。
